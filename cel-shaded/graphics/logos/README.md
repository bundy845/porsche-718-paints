# Hood team logo source

Copied `2-old-2-slow-driver-door.psd` and its PNG preview from `Paints/general-logos/2-old-2-slow/` on 2026-10-18. The saved general asset came from `Paints/MWM Season 12/Porsche 992_2 Cup-Recovered.psd`, layer `Paintable Area > 2old2slow logo - Driver Door`.

The PSD retains the original embedded smart object. Its upright 226 x 212 source appearance is the skeleton-and-piston `2OLD2SLOW` logo. The shared 718 master uses a duplicate of that original smart object, rotated 90 degrees clockwise and uniformly scaled for the hood. The 992 door placement was not reused.

718 hood placement: UV bounds x438-663, y1150-1390, centered near (550,1270). Nose is toward lower UV x; windshield is toward higher UV x. The rotation puts the logo's top toward the windshield and lettering toward the nose, so it reads from the front. See `../../design/diagnostics/hood-logo-wire-proof.png` and the shared mapping notes. Placement still requires an in-car view.
