# Porsche 718 GT4 shared car profile

Use [mapping/README.md](mapping/README.md) before placing artwork on this car. The profile applies to the 2048 × 2048 `Porsche 718 GT4.psd` from `119_template_P718.zip`; compare the template Wire layer before reusing coordinates with another version.

The mapping belongs to the car and is shared by all 718 GT4 liveries. Livery artwork, approvals, and export history remain in each livery's folder.
